Os diretórios `sprint-03` a `sprint-12` guardam evidências por etapa. Os PDFs
anteriores e a documentação da Sprint 02 mantêm o planejamento e os resultados
da época. Para comportamento atual, use os manuais e a documentação final acima.
O modelo relacional da Sprint 09 continua válido, sem mudança estrutural nas
Sprints 10 a 12. As capturas dos novos manuais ficam em `sprint-11/assets`.

O repositório é público. Os links relativos funcionam ao abrir estes arquivos
no GitHub; o PDF principal também incorpora os dois manuais completos, sem
depender de acesso a uma aplicação publicada.
